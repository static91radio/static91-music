Static 91 Radio - Privacy Policy and Terms of Service

Last updated: 9 November 2026

Who we are

Static 91 Radio is a 24/7 livestreamed alternative rock music channel on YouTube, with a sister lofi channel, Second Steeping. The music is created and produced with AI tools by the channel owner and offered free, with credit, to other creators. Contact: via the YouTube channel at youtube.com/@static91radio.

The Static 91 uploader (our YouTube API client)

The "Static 91 uploader" is a private command-line tool run by the channel owner on the owner's own computer. It uses YouTube API Services to upload the owner's own videos to the owner's own YouTube channels, set titles, descriptions, tags and thumbnails, add videos to the owner's playlists, schedule publish times and post comments.

  • It has a single user, the channel owner. It is not offered to, installed by, or operated on behalf of anyone else.
  • It does not collect, store, share or sell any personal information about any other person.
  • The only data it stores is the owner's own OAuth access token, saved on the owner's computer, used solely to authenticate with YouTube. It can be revoked at any time at Google security settings.
  • It does not read, display, download or republish any YouTube content belonging to others, and it does not serve advertising.
  • It uses YouTube API Services and is therefore subject to the YouTube Terms of Service and the Google Privacy Policy.

This website

This site (static91radio.github.io) is a static page hosted on GitHub Pages. We do not run analytics, set cookies or collect any information from visitors. GitHub may log standard web server data as described in the GitHub Privacy Statement.
